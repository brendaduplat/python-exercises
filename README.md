# Python Exercises

Python exercises I wrote while studying, organized by topic.
I'm building this foundation as part of my transition into data engineering.

## Contents

| Folder | Topic | 
|--------|-------|
| `conditionals` | `if` / `elif` / `else` statements |
| `loops` | `for` and `while` loops |
| `functions` | Defining and reusing functions |
| `data_structures` | Lists, dictionaries and nested structures |
| `list_comprehension` | Building lists with list comprehensions |

## Requirements

- Python 3.8+ (tested with Python 3.14.3)

## Notes

This repository contains study exercises. Each folder groups
